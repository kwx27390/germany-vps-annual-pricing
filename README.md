## 500Mbps 端口和 CN2 GIA 回程，分别管什么

500Mbps 指的是这台机器在机房出口的端口速率上限，不承诺你任何时刻都能跑满，更不决定回国速度。决定回国体验的是回程路由。

德国机房本身带宽不缺，缺的是把数据送回国内那条路。普通德国 VPS 走国际公共线路，晚高峰路由可能绕美国、绕日本，延迟翻倍、丢包上升。CN2 GIA 是中国电信的优质承载网，CMIN2 是中国移动的同类产品，走这两条线回国，路径更直，晚高峰波动小。

AkkoCloud 德国机房给出的配置是：电信去程 GIA、回程 GIA；联通去程 GIA、回程 GIA；移动去程 CMIN2、回程 CMIN2。关于移动回程，几份公开资料说法不完全一致，有的写 CMIN2，有的写三网回程统一走 GIA，能确认的共同点是三网都做了优化，不存在某一家的流量被丢到普通公网上绕路。

自己验证比看参数靠谱。有资料给出测试 IP `185.217.109.94`，可以 ping 一下看延迟和丢包。第三方测评提到法兰克福节点延迟在 180ms 上下，普通欧洲线路通常 230ms 以上，但这个数字跟你所在城市、宽带运营商关系很大，同一台机器在广东和新疆测出来能差几十毫秒，自己跑一遍再决定。
